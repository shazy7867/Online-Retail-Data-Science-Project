# Online Retail Data Science Project

## Project Overview

This repository contains the practical Python code, dataset and supporting
files used for the Online Retail Data Science Project.

## Files

- `SOFTWARE.ipynb` – Complete Python notebook containing the data cleaning,
  exploratory data analysis, statistical analysis, machine learning models,
  model evaluation and results.
- `OnlineRetail.zip` – Dataset and supporting project files required for
  running the practical work.

## How to Run

1. Download or clone this repository.
2. Extract `OnlineRetail.zip`.
3. Open `SOFTWARE.ipynb` using Jupyter Notebook, JupyterLab or Google Colab.
4. Ensure the required dataset files are available in the same working
   environment/location used by the notebook.
5. Run the notebook cells from beginning to end.

## Requirements

The notebook uses Python and the following libraries:

- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
